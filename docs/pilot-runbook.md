# LaunchFlow first pilot

Before inviting a live project, complete the deployment and restore checks in [operations.md](operations.md). Start with one synthetic agency, one reviewer and one content request. Verify review history and revocation, then use one real project per pilot agency with their agreement.

Record prior project baseline, setup time, minutes spent chasing copy, overdue days, time between first submission and approval, and any use on a second project. Keep requested price, stated interest, agreement and payment in separate fields. Contact the project lead after the first approval for a short workflow interview. Assess repeat use and paid commitments before expanding scope.
